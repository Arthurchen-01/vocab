## 附带发现的造假问题（已修 + 已加门禁）

批量/导入路径曾用**编造的"字幕"**冒充讲座原文并恒置 `has_subtitles=true`；`/api/import/link` 甚至**从不抓字幕**，
仅粘贴链接的导入 100% 会产出例句从未被说过的假词表。现已改为**先真的抓取**（yt-dlp / B站 CC / SRT），
抓不到就如实报无并返回 422 给出指引；`S8 反造假门禁` 15/15 守住回归。

## 本轮同步修掉的工具链缺陷

| 缺陷 | 影响 |
|---|---|
| `S0b` 一次要 AI 选整份词表 | 输出超限、JSON 截断导致阶段失败 → 改为按讲座时间窗分批 |
| 考试词表被当作"占用者" | 290 个真实出现的词被排除（含 `justice`）→ 只排除其它**讲座**剧集 |
| 候选清单被当白名单 | 白扔 100 个好词 → 改判据为"真出现 ∧ 未被其它讲座占用"，救回 37 个 |
| `S4c` 把全部释义标成"自己写的" | 导入的词典释义被严格文体门禁误杀 207 条 |
| `S6b` 不在流水线阶段表里 | 每次重建词库后 `taught_in` 丢失（跨集复用显示为 0）→ 已并入 S6 之后 |
| `bank_only` 只置不清 | 后来被收录的词仍显示"历史词" |
| `load_exam_decks()` 每次重读文件 | 音频富化被丢弃 → 考试词表卡片**根本没有 `audio_url`**（播放即坏）→ 改为缓存 |
| 音频 URL 无条件拼接 | 新卡组指向不存在的 mp3 → 服务端改为"存在才给文件，否则给按需 TTS" |
| 导出门禁拿 CSV 原始字节比子串 | 释义内引号被转义成 `""`，10 个词被误报缺失 |
| `server.py` 用 `int(sys.argv[1])` 解析端口 | 任何带参数的启动器都会让应用崩在导入期 |
| 客户端 SSH 抖动 / 结束条件写死阶段名 | 任务成功却报失败 → 逐命令重连 + 按形态判断结束 |
